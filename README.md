# 📚 RAGsystem

![Last Commit](https://img.shields.io/github/last-commit/SwAstikAaa66/RAGsystem)

> A **Retrieval-Augmented Generation (RAG)** system built with Python — combining the power of search + generation for smarter responses.

---

## 🚀 Features
- 🔍 **[Retrieval](ca://s?q=Explain_Retrieval_in_AI)**: Fetches relevant data from your custom dataset.
- 🤖 **[Generation](ca://s?q=Explain_Generation_in_AI)**: Produces contextual answers using LLMs.
- 📂 **[Data Handling](ca://s?q=Data_handling_in_AI_projects)**: Organized `Data/` folder for easy dataset management.
- ⚡ **[Main Script](ca://s?q=Explain_main.py_in_Python_project)**: Run everything via `main.py`.
- 🛠️ **[Requirements](ca://s?q=Explain_requirements.txt_in_Python)**: Simple setup with `requirements.txt`.

---

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/SwAstikAaa66/RAGsystem.git

# Navigate into the folder
cd RAGsystem

# Install dependencies
pip install -r requirements.txt
```
## 🖥️ Usage
```bash
# Run the main script
python main.py
1. Place your dataset inside the Data/ folder.
2. Customize retrieval logic in main.py.
3. Extend generation with your preferred LLM.
```
